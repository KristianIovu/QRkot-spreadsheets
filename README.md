# QRkot-spreadsheets - Благотворительный фонд поддержки котиков

## Описание проекта

QRKot - это веб-приложение для управления благотворительными сборами.
Фонд собирает пожертвование на помощь кошачьей популяции: корм,
мед. обследование, содержание приютов и т.д..

## Основные возможности

- **Целевые проекты** - создание сборов с указанием требуемой суммы
- **Пожертвования** - приём пожертвований от пользователей с комментариями
- **Автом. инвестирование** - средства автом. распределяеются между открытыми
проектами в порядке их создания
- **Закрытие проектов** - сбор автом. закрывается при достижении нужной суммы
- **Регистрация и аутентификация** - JWT-токены, регистрация по email
- **Персонализированные пожертвования** - каждое пожертвование привязано к пользователю
- **Отчёт в Google Sheets** - формирование отчёта о скорости закрытия проектов
- **Разграничение прав доступа**:
  - Обычные пользователи: создают пожертвования, видят свои пожертвования
  - Суперпользователи: управляют проектами, видят все пожертвования
- **Полная документация API** - Swagger UI доступен после запуска

## Технологии

- **FastAPI** - веб-фреймворк
- **SQLAlchemy 2.0** - база данных
- **Pydantic** - валидация данных
- **Aiosqlite** - асинхронный драйвер SQLite
- **FastAPI Users** - аутентификация и управление пользователями
- **JWT** - JSON Web Tokens для авторизации
- **Google Sheets API** - формирование отчётов
- **Aiogoogle** - асинхронный клиент Google API

## Установка и запуск

1. Клонирование проекта
```https://github.com/KristianIovu/QRkot-spreadsheets.git```

2. Создание и активация виртуального окружения (в зависимости от ОС)
cd cat-charity-1
source venv/Scripts/activate

3. Установка зависимостей
pip install -r requirements.txt
pip install aiogoogle pydantic-settings

4. Запуск приложения
uvicorn app.main:app --reload

5. Открытие документации
http://localhost:8000/docs
